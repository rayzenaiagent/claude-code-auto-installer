# claude-code-auto-installer

نصب خودکار Claude Code.

## Linux / macOS

```bash
curl -fsSL https://raw.githubusercontent.com/rayzenaiagent/claude-code-auto-installer/main/install.sh | bash
```

## Windows (PowerShell)

```powershell
irm https://raw.githubusercontent.com/rayzenaiagent/claude-code-auto-installer/main/install.ps1 | iex
```

اول با npm نصب می‌کنه (نیاز به Node.js 18+)، اگه نشد از نصب‌کننده‌ی رسمی استفاده می‌کنه.
